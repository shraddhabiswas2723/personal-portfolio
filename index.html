          One-click refresh: check every job board when you press Refresh (optional)

          Without this, Refresh loads the newest list the hourly check has saved. With it, Refresh also asks GitHub to check every company job board right away, and the new openings appear about 3 minutes later. It needs a GitHub token that can only start job checks:

          1. Open GitHub → new fine-grained token (sign in as shraddhabiswas2723).
          2. Name it "Job refresh", pick an expiry (90 days is fine), and under Repository access choose Only select repositories → personal-portfolio.
          3. Under Permissions → Repository permissions, set Actions to Read and write. Leave everything else as it is.
          4. Press Generate token, copy it, and paste it here.

          The token is saved in this browser only, never in the site's code or your backup. It can start and cancel job checks but can't change your site. Delete it on GitHub any time to switch this off.
